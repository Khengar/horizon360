Horizon 360 SDK Documentation

Overview & Setup

The Horizon 360 Node.js SDK provides a type-safe, Singleton-based interface to interact with the CDP backend. It manages JWT authentication automatically and exposes methods to register schemas, track events, and retrieve customer profiles.

Prerequisites

Ensure the SDK file horizon360.ts is included in your project directory and install the required HTTP client:

npm install axios

Initialization

The SDK utilizes a Singleton pattern. You must call initializeApp() exactly once at the entry point of your application (e.g., server.ts or app.ts). Once initialized, the module retains the authenticated state globally.

Parameters: SDKConfig

Property Type Description
baseUrl string The root URL of the Horizon 360 backend (e.g., http://localhost:8000).
username string The admin or system user account name used for JWT generation.
password string The password for the designated account. 
import { initializeApp } from './horizon360';

async function boot() {
  await initializeApp({
    baseUrl: 'http://localhost:8000',
    username: 'root',
    password: 'root'
  });
  console.log('CDP SDK Initialized');
}
boot();

Tracking Events

Use the track() method to stream events into the CDP. Events are validated against the Schema Registry synchronously and processed into customer profiles asynchronously.

Parameters

Parameter Type Description
eventName string The normalized event name (must follow the domain.action format).
payload Object The raw event data. Must contain an identifying key (like email) as defined in your schema.
schemaVersion number Optional. Defaults to 1. 
import { track } from './horizon360';

async function registerUser(email, plan) {
  const result = await track('account.created', {
    email: email,
    plan_tier: plan,
    consent: { marketing: true }
  });
  console.log('Event queued:', result.event_id);
}

Customer Profiles

Use the getCustomer() method to retrieve the real-time, unified identity record of a user, including their chronological timeline and dynamically merged attributes.

Parameters

Parameter Type Description
email string The exact primary email address of the customer to lookup. 
import { getCustomer } from './horizon360';

async function checkProfile(email) {
  const profiles = await getCustomer(email);
  if (profiles.length > 0) {
    console.log('Merged Attributes:', profiles[0].attributes);
    console.log('Event Timeline:', profiles[0].timeline);
  }
}

Schema Registry

Use registerSchema() to define new event structures. Incoming events will be validated against this structure before being accepted by the backend.

Parameters

Parameter Type Description
eventName string The normalized event name (e.g., cart.viewed).
jsonSchema Object A valid JSON Schema definition object.
version number Optional. Defaults to 1. 
import { registerSchema } from './horizon360';

async function setupSchemas() {
  await registerSchema('cart.viewed', {
    type: 'object',
    properties: {
      email: { type: 'string', format: 'email' },
      item_count: { type: 'number' }
    },
    required: ['email']
  });
}

Full Example Integration

Below is a complete, copy-paste ready example of how to initialize and utilize the SDK inside a typical controller or script environment.

import { initializeApp, track, getCustomer } from './horizon360';

async function executeIntegration() {
  // 1. Initialize
  await initializeApp({
    baseUrl: 'http://localhost:8000',
    username: 'root',
    password: 'root'
  });

  // 2. Track an event
  await track('system.test_fired', {
    email: 'developer@example.com',
    status: 'online'
  });

  // 3. Allow worker processing time (example only)
  await new Promise(resolve => setTimeout(resolve, 2000));

  // 4. Retrieve Profile
  const profile = await getCustomer('developer@example.com');
  console.log(JSON.stringify(profile, null, 2));
}

executeIntegration();
