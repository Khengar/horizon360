# Horizon 360 CDP

An enterprise-grade Customer Data Platform featuring a Python/Django backend and a React/Tauri frontend.

## Architecture
- **Backend:** Django, Django REST Framework, Celery, PostgreSQL, Redis.
- **Frontend:** React, Tailwind CSS v4, Vite, Lucide Icons.

## Quick Start
1. `cd horizon360`
2. `docker compose up --build`
3. Access the backend at `http://localhost:8000`
4. Access the frontend at `http://localhost:1420`
5. Access the Superadmin at `http://localhost:8000/admin`
